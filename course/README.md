# Tiny Transformer Interpretability — a beginner course

A self-contained, 10-page web course that teaches mechanistic interpretability from
scratch, built entirely around the 51k-parameter causal pair-sort decoder studied in
`research/sort_scaling/`. It explains how the transformer is defined and works, then
walks through every interpretability technique used on it — with the motivation
("why"), the method ("what"), and the results and observations — ending with the full
algorithm the model learned and an honest account of what we got wrong.

## View it

Open `index.html` in a browser (everything is local and self-contained — figures,
styles, and the two interactive 3D viewers are all in this folder):

```bash
xdg-open course/index.html      # or just double-click it
```

## Contents

1. What is interpretability? — why, and the question we chose
2. How a transformer works — tokens, residual stream, attention, MLPs
3. Our model and its task — pair-sort, the architecture, why a decoder
4. Reading attention — heatmaps and finding an induction head
5. Causal methods — ablation, activation patching, logit attribution
6. Probing & geometry — probes, PCA, effective dimensionality, embeddings
7. The algorithm it learned — the full circuit and the comparison mechanism
8. Universality, failures & honesty — seeds, breakage, and corrections
9. What you learned — the toolkit and the big ideas

## Reproduce / edit

Lesson bodies are the HTML fragments in `parts/`; `build.py` wraps each in the shared
template (sidebar, nav) to produce the top-level `*.html` pages:

```bash
python course/build.py
```

Figures live in `figures/` (copied from `reports/figures/`); the interactive viewers
`stream_3d.html` and `embedding_3d.html` are generated by
`research/sort_scaling/build_stream3d.py` and `build_emb3d.py`.
