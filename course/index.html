Overview

What this course is and the question it answers

Can we take a neural network apart and explain, mechanism by mechanism, exactly how it does what it does?

This course answers that question for one very small transformer — about 51,000 parameters, small enough to understand completely — that learned to sort. By the end you will be able to read its attention patterns, run causal experiments on its internals, decode what its activations represent, and write down the algorithm it discovered, with evidence for every step.

You do not need to have studied transformers before. We build the model up from tokens and vectors, then learn each interpretability technique on a real example where you can see it pay off. Everything here is reproducible from the code in research/sort_scaling/.

Why this model

Big language models are too large to understand in full. A tiny model trained on a single, well-defined task is a model organism: simple enough to explain completely, yet it still learns real, surprising circuits. What we practise here — attention analysis, ablation, patching, probing — is exactly what researchers use on the big models.

The story in one paragraph

We wanted to know whether a transformer, scaled up to sort long sequences, would discover a sorting network (the comparison circuits from computer science). It did not. Over a small alphabet it found counting sort instead. So we changed the task to force real routing — sort (key, value) pairs and carry each value along — and discovered that the usual encoder could not learn it at all. Switching to a causal decoder cracked it, and inside we found a clean induction head copying values and a threshold-cliff readout choosing keys. Then we checked whether any of it generalizes, where it breaks, and what we got wrong along the way.

The punchline you will earn: a model's architecture decides which algorithm is even reachable, and the geometry it learns follows the computation it has to perform.
