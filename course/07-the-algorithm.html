The algorithm it learned

Assembling the circuit and cracking the comparison

We have gathered attention patterns, causal effects, and representations. This lesson assembles them into one thing: the algorithm the model learned, with a line of evidence behind every step. This is what all the tools were for.

The circuit, laid out

The algorithm, as pseudocode

Reading the evidence together, the model runs this:

# ── Layer 0: gather & bind (setup) ──
for each input value position:
    stamp it with its own key's identity      # L0 precursor heads
at SEP:
    gather the set of present keys here        # a "menu", read from SEP later

# ── Generate the sorted pairs, left to right ──
threshold = -inf
for q in range(n):
    # KEY step
    threshold = max key emitted so far         # L1H1 reads the output
    emit  smallest present key > threshold      # threshold-gated readout
    # VALUE step
    emit  value whose key == the key just emitted   # L1H0 induction copy

How does it actually compare? A cliff.

"Pick the smallest present key greater than the threshold" sounds like it needs a comparison loop. It does not. The readout is a single, roughly linear function of the residual, shaped like a cliff. Measuring the logit the model assigns to each present key as a function of (key − threshold):

key − θ−10−10+1+2+5+20
mean logit−2.04.34.630.327.418.9−2.0
There is an ~8-logit cliff the moment a key exceeds the threshold, then a gentle decline. The argmax is automatically the smallest key just above θ. "Greater than" is not a loop — it is a fixed readout with a cliff, and argmax does the choosing.

So the comparison never scans candidates or computes ranks. Layer 0 builds a menu of present keys; L1H1 supplies a moving threshold; and a cliff-shaped linear readout emits whatever key sits just above it. As the threshold sweeps upward step by step, the output marches through the keys in order — that is the sort.

Where the story gets honestly fuzzy

Two pieces stayed distributed rather than crisp. The "menu" is not a tidy object you can transplant out of SEP — the candidate identities are spread across the layer-0 residual. And the threshold is a ~5–8-dimensional code, not a single direction. The mechanism is pinned down; a minimal set of named directions for it is not. We flag this rather than pretend otherwise.

And the MLPs?

A tidy surprise from ablation: the layer-1 MLP barely matters (removing it costs a few percent) — the selection and the copy are both done in attention. The layer-0 MLP is essential for keys (removing it crashes key accuracy to 0.20), yet probes show it does not build the readable key menu — so what exactly it contributes stays unlocalized. Not every question resolves cleanly, and saying so is part of the craft.

The model, understood

Two channels: sort-by-generation for keys (running-max threshold + a cliff readout) and an induction head for values, both computed in layer-1 attention off a layer-0 setup, with SEP as a scratchpad. Not a comparison network — a generate-and-threshold machine.

One model, fully explained. But is any of this general — or did we just narrate one lucky network? That question, and where the model breaks, is next.
